How was this made?

This website was authored using AI tools. I didn't even write the stuff on this page, it was generated by AI. I just provided the prompts and edited the output a bit. The code is hosted on GitHub and the project is open source. The data comes from OpenData Bonn, which is a collection of public data sets provided by the city of Bonn. The data is available at Open Data Bonn. The maps are generated using Leaflet, a JavaScript library for interactive maps. OpenStreetMap is used as the base map layer, and the data is displayed using markers and popups.

Who We Are

We are dedicated to helping the Bonn community with information and resources about bulky waste disposal. Our goal is to make it easier for residents to find, share, and manage bulky waste pickups.

Our Mission

We strive to promote sustainability and community engagement by providing up-to-date information and a platform for sharing resources.
